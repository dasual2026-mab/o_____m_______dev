| 폴더 | 담는 것 |
|---|---|
| `app/` | 앱. Expo와 React Native |
| `server/` | 서버 API(Supabase Edge Functions)와 DB 변경 파일 |
| `admin/` | 관리자 콘솔. 웹 |
| `shared/` | 공통 정의. 창구의 주소, 값 이름, 오류 번호, 상한 |

- 일하는 규칙은 `CLAUDE.md`에 있다.
